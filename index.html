Abstract

We introduce PBEBench, a contamination-resistant benchmark for evaluating large language models on sound law induction—the task of recovering phonological rewrite rules from input-output examples expressed as a Programming by Examples (PBE) problem. Sound law induction is a classical problem in historical linguistics that requires multi-step symbolic reasoning over structured examples, making it an ideal testbed for measuring genuine reasoning ability beyond pattern matching or memorization.

PBEBench operationalizes this as a two-task evaluation: (1) Sound Law Synthesis, where models must synthesize a sequence of context-sensitive rewrite rules (expressed in a restricted DSL) that correctly transforms given input strings into output strings across all provided examples; and (2) Rule Reordering, where models receive a set of correct rules in shuffled order and must determine the unique correct ordering. The benchmark features controllable difficulty via complexity parameters, knowledge-free construction (rules are drawn from uncontaminated historical corpora), and strong correlation with real sound law induction performance—outperforming existing benchmarks.

Overview

PBEBench frames sound law induction as a Programming by Examples problem. Given a set of (input, output) string pairs illustrating a phonological change, an LLM must synthesize a correct sequence of rewrite rules in a domain-specific language (DSL) that reproduces every transformation.

Each problem instance specifies the DSL, a set of training examples, and optional held-out test examples for validation. The benchmark is constructed from real historical linguistics data, making it highly resistant to data contamination while remaining knowledge-free (no linguistic knowledge is required to solve problems from the examples alone).

Difficulty is controlled via the complexity parameter: the number and type of interaction constraints (BFCC relations) present in the rule set. Higher complexity requires reasoning about ordering-sensitive rule interactions.

Key Findings

PBEBench-Lite is the strongest predictor of real Sound Law Induction performance.

With Pearson r = 0.827 (p = 0.0017), PBEBench-Lite outperforms both CLUTRR (r = 0.636) and SLR-Bench (r = 0.809) as a proxy for a model's ability on real historical linguistics tasks.

Additional Observations

  • Reasoning models dominate the top of the synthesis leaderboard, with GPT-5, gpt-oss-120b, and Gemini 2.5 Flash in the top 3.
  • Edit Similarity diverges from Pass@1 for Claude models, which tend to produce well-formed but non-passing programs—suggesting they capture the structure but fail on edge cases.
  • Validity and correctness decouple: o3-mini achieves 99.5% valid rate but only 19.6% Pass@1, indicating high syntactic competence but low semantic reasoning.
  • Open-source MoE models (Qwen3-30B-A3B) are competitive with much larger dense models at <30% of the parameter count.

About PBEBench

PBEBench tests models on a form of multi-step reasoning that is genuinely hard: reasoning about ordered, context-sensitive rewrite rules that must collectively explain a set of input/output string transformations. The domain is historical phonology—the study of how sounds change over time in human languages—chosen because it is combinatorially complex, knowledge-free (no memorized facts help), and entirely absent from standard pre-training corpora.

BFCC Rule Interactions

The central challenge in PBEBench is reasoning about rule ordering interactions. When two rewrite rules A and B can both apply to a string, their relative order can matter. These interactions are classified into four BFCC types:

Feeding (F)

Rule A creates the context for Rule B to apply. Applying A before B allows B to fire on more strings. The interaction is productive.

Bleeding (B)

Rule A removes the context that Rule B would require. Applying A before B prevents B from firing on those strings.

Counter-Feeding (CF)

Rule B is applied before A, even though A could have fed B. The order chosen counteracts a potential feeding relationship.

Counter-Bleeding (CB)

Rule B is applied before A, even though A could have bled B. The order preserves applications that would otherwise be blocked.

Why Contamination-Resistant?

PBEBench draws its rule sets from historical sound change data across dozens of language families. These rule sets are not available in structured, machine-readable form in standard pre-training corpora, and the PBE framing (provide examples, synthesize rules) is distinct from any existing NLP task. Furthermore, the controllable difficulty axis means that we can always generate harder instances that a contaminated model would fail on, providing a renewable evaluation resource.

Dataset

PBEBench-Lite on HuggingFace 🤗

The PBEBench-Lite evaluation split is publicly available on HuggingFace Datasets. It contains a curated set of sound law synthesis and rule reordering problems spanning a range of difficulty levels (complexity 1–20), with complete DSL specifications, training examples, and held-out test cases.
